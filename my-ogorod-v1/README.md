# Мой Огород — MVP V1

Мобильный PWA-прототип для одной пользовательницы. Главный фокус — дневник посадок, примерные сроки всходов/сбора и простые задачи.

## Запуск
Требуется Node.js 20+ (рекомендуется актуальная LTS-версия).

```bash
npm install
npm run dev
```

## Проверка production-сборки
```bash
npm run build
npm run preview
```

## Что включено
- Четыре раздела: Обзор, Участок, Посадки, Задачи.
- Условная схема участка с перетаскиванием объектов через dnd-kit.
- Посадки с датой посева, примерными сроками всходов и сбора.
- Недельные задачи с отметкой выполнения.
- localStorage и экспорт JSON.
- Конфигурация PWA через vite-plugin-pwa.

## Ограничения MVP
- Данные хранятся только в текущем браузере/устройстве.
- Карта условная, не в масштабе.
- Каталог и сроки — демонстрационные ориентиры, не гарантия урожая.
- Реальный прогноз погоды и автоматические повторные посевы не подключены.
- Перед публикацией стоит добавить PNG-иконки PWA и проверить сборку на целевом хостинге.
